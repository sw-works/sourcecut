# Research board layout directions

Three layout directions for the research board, drawn on the captured Bitterroot
board so density is judged against real content: every quote, waypoint, day
state and count comes out of `data/examples/bitterroot-september-1805.json`.

- **A · Instrument bench** (`InstrumentBench.dc.html`) — timeline and route as
  one pinned clock above three parallel evidence columns.
- **B · Reading room** (`ReadingRoom.dc.html`) — requirements rail, evidence at
  full reading width, a context rail that never scrolls away.
- **C · Survey then drill** (`Main.dc.html`) — **chosen.** The clock full width,
  then brief, route and archive review as three cards, then the open
  requirement as one workbench.

`build.py` regenerates all three artboards and `canvas.json` from the captured
board:

```sh
python3 docs/ui_redesign/board_layout/build.py
```

`research-board-layouts.html` is the seeded canvas that was published; it is
regenerated by the design tooling, not by hand.
