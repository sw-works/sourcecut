One captured board per curated research scope, named `<scope_id>.json` to match
data/reference/research_scopes.json.

Written by sourcecut-capture-example; read at build time by apps/web/src/pages/index.astro,
which loads every scope that has one and opens on the scope marked `default`.

These are real runs kept as they came out. Never hand-edit one: a board presented as real has
to have been produced by a real run. Re-capture instead.
